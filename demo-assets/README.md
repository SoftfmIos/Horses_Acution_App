# Demo media provenance

`photos/horse-01.jpg` through `horse-06.jpg` are optimized copies of fictional horse images generated for this demo using OpenAI image generation on 13 November 2026. They represent Shams, Badr, Najma, Sahab, Rimal and Barq, respectively. The source PNGs were retained in the generation workspace; generated images are not photographs of real academy horses.

`avatar-club.jpg` uses the academy logo already supplied in this repository. `avatar-riding.jpg` and `avatar-polo.jpg` use existing academy imagery from the iOS app assets, which the user authorized for this project. User avatars may be objects, horses or academy images rather than faces.

`documents/` contains two bilingual fictional sample PDFs per demo horse. All identify themselves as demonstration material. They are not official passports, medical certificates, proof of ownership or treatment instructions.

`manifest.json` identifies the files, their checksums and the horse IDs for document linkage. The remaining horse photos and equestrian instructor avatars are acquired by the cPanel photo-only importer from CC0/public-domain Wikimedia Commons images; their source and licence metadata is saved with the imported photo and private cache entry.

See `docs/DEMO_MEDIA.md`. Importing these files never resets users, bookings or balances.
