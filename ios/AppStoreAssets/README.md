# App icon

`AppIcon-1024.png` is the App Store artwork for Riyadh Polo Hills, matching the packaged `AppIcon.appiconset`. It uses the existing academy crest on the brand ivory background.

- 1024 × 1024 pixels, RGB PNG, no transparency.
- Full square artwork; iOS applies the rounded icon mask.
- The Xcode target already selects this icon with `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`.
- Codemagic compiles the icon into the IPA; no separate icon upload is required for TestFlight. This copy is provided for easy artwork review/download.
